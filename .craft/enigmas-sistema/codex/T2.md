## Step 2 — publica.py
usage: `python3 publica.py <stem>... [--dry DIR]` (stem = yaml file name without `.yaml`, NOT its `deck:` field).
- Run `checa.checa(path)` first; any bloqueante → print them, exit 1, write nothing.
- Bank JSON (UTF-8, `ensure_ascii=False`):
  `{stem, versao, faceis:[{id, enunciado, alternativas:{A..E: text}, correta: letter, feedback:{letter: text}, parabens}], dificeis:[{id, tolerancia, parabens, combos:[{enunciado, valor, erros:[{valor, feedback}]}]}]}`
  - `versao` = first 12 hex chars of sha256 of the yaml file bytes.
  - easy: copy fields; `alternativas` keep the yaml letters (the server shuffles).
  - hard: `tolerancia` = `checa.tolerancia(q["tolerancia"])` (float); one combo per element of `itertools.product(*parametros.values())`, in that order, env = `dict(zip(parametros, values))`; `enunciado` = `checa.preenche(q["enunciado"], env)`; `valor` = `checa.calc(q["resposta"], env)`; `erros` = `[{valor: checa.calc(e["expressao"], env), feedback: e["feedback"]}]` for each `erros_provaveis`.
  - Drop every other yaml field (conceito, slide, etapas, conta, auditoria…).
- `index.json` = `{"caixas": [stem|null ×13], "versoes": {stem: versao}}`. Box order (0-based):
  `historia, regressao-linear, perceptron, autocodificadores, redes-convolucionais, redes-de-grafos, redes-recorrentes, memoria-longa-de-curto-prazo, redes-adversariais, professor-aluno, transformers, autoaprimoramento, crises`.
  Only stems named on this command line (and, without --dry, those already in the remote index) are non-null.
- `--dry DIR`: write `DIR/bancos/<stem>.json` and `DIR/bancos/index.json`.
- Without `--dry`: store = repo `lsfcin/academy-teaching`, branch `enigmas-site`. For each file: `gh api repos/lsfcin/academy-teaching/contents/bancos/<name>?ref=enigmas-site` to get the sha (404 = new), then `gh api -X PUT … -f message="enigmas: publica <stem> <versao>" -f branch=enigmas-site -f content=<base64> [-f sha=…]`. Read the remote index first and merge (keep other published stems).
- First line of the file: `# publica.py — <one line what it is for>. usage: …` (same style as checa.py).
