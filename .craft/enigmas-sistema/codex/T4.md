## Bank JSON (input, produced by a Python publisher — build a small fixture by hand in the test)
`{stem, versao, faceis:[{id, enunciado, alternativas:{A..E: text}, correta: letter, feedback:{letter: text}, parabens}], dificeis:[{id, tolerancia, parabens, combos:[{enunciado, valor, erros:[{valor, feedback}]}]}]}`. A real bank has 6 easy + 3 hard = 9 ids.

## Deck rule (signed by Lucas — implement exactly)
- A round = 3 cards: 2 easy + 1 hard. Box closes (`fechou`) iff the 3 are right in the same round. No exhaustion exception.
- `baralho` (queue, 9 ids at start, order = ids sorted by hex HMAC(`ordem|${matricula}|${stem}|${id}`)); `acertos` (list, oldest first).
- Serve: hard = first hard id in `baralho`, else the oldest hard in `acertos`; easy = first 2 easy ids in `baralho`, filled from the oldest easy in `acertos`. Card order shown: easy, easy, hard.
- Grade, per card: right and from baralho → leaves baralho, appended to acertos; right and from acertos → stays; wrong → to the tail of baralho (removed from acertos if it came from there).
- Easy letters shuffled per round: permutation of the bank's letters = sort by hex HMAC(`letras|${matricula}|${stem}|${qid}|${n}|${letra}`); the student answers the shown letter, the server maps it back.
- Hard combo: uint32 big-endian of the first 4 bytes of HMAC(`combo|${matricula}|${stem}|${qid}|${n}|${versao}`) mod combos.length.
- HMAC = HMAC-SHA256 via `crypto.subtle` only (Node ≥18 and Workers), key = the UTF-8 bytes of the secret string as given (64 hex chars, NOT hex-decoded).
- Hard answer: accepts `2,5` / `2.5` / surrounding spaces; not a number → throw `{status: 400}`, nothing graded. Right iff |given − valor| ≤ tolerancia + 1e-9. Wrong → `feedback` = every `erros[].feedback` whose valor is within tolerancia of the given answer (collision = all of them); none matches → `["não bate com nenhum erro previsto: refaça as etapas com calma"]`. Easy wrong → `[feedback[original letter]]`. Right → `[parabens]`.

## API
- `hmacHex(secret, msg) → Promise<string>`
- `novo(banco, matricula, secret) → Promise<Estado>`
- `servir(estado, banco, matricula, secret) → Promise<{estado, rodada}>` — `estado.aberta` set ⇒ the same round back, nothing changes. Otherwise n = estado.n + 1, build `aberta` (ids, versao, combos, letras) and store it.
- `corrigir(estado, banco, n, respostas, matricula, secret) → Promise<{estado, resultados, fechou}>` — `n === estado.ultima?.n` ⇒ `estado.ultima` back unchanged (idempotent resend); `n !== estado.aberta?.n` ⇒ throws `{status: 409}`; after grading: `aberta = null`, `ultima = {n, resultados, fechou}`, `estado.n = n`.
- `publico(rodada, banco) → Questao[]` — the only shape that leaves the server: easy = `{id, tipo:'facil', enunciado, alternativas}` with alternatives relabelled A..E in the shuffled order; hard = `{id, tipo:'dificil', enunciado}` of the chosen combo.
- Types: `Estado = {versao, baralho: id[], acertos: id[], n: int, aberta: {n, ids: id[3], versao, combos: {qid: int}, letras: {qid: string[]}} | null, ultima: {n, resultados, fechou} | null, fechou: bool}`; `Resultado = {id, certo: bool, feedback: string[]}`.
- Invariants (each gets a test): no `correta`, `valor`, `erros`, `feedback`, `combos` anywhere in `publico` output; |baralho| + |acertos| = 9 always; `fechou` never goes back to false.
